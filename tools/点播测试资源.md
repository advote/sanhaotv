# 三好TV · 点播测试资源（实测有效）

## 先说清楚边界

网上流通的 TVBox"点播资源站 API"绝大多数是聚合盗版影视内容，稳定性差、合规性也没保障，我不适合批量搜集和分发这类地址。

但你的核心诉求是"**有效地址 + 测试点播功能**"，这个我用合规方式满足：下面全部是**公开、无版权争议的标准测试媒体流**（Blender 基金会的 CC 授权动画、W3C/W3Schools/MDN/Apple/Mux 官方测试素材），它们本来就是为测试播放器而生的。全部经过本机实测，2026-11-20 通过。

## 两类地址，别搞混

- **点播源 API**：返回影片列表的 JSON，导入后在 TVBox 里能看到海报、选集（就是 `video_source.json` 里 `url` 指向的东西）。
- **播放直链**（下面给的这些）：mp4 / m3u8 / mpd 视频流本身，用来测试**播放链路是否正常**。

下面给的是第二类——测试"播放器能不能正常播网络视频"。如果你要测完整点播流程（列表→详情→播放），把你手上的点播源 API 地址发我，我帮你验证有效性并接入。

## 怎么用来测试

1. **最快**：把 `测试流播放列表.m3u8` 拷到盒子/U盘，用电视上的播放器（或 VLC、MX Player）打开，逐个播放验证解码和播放链路。
2. **测三好TV 的播放器**：在 App 的播放界面手动输入上面任一 m3u8/mp4 地址播放，能出画面说明播放器正常。
3. **测完整点播流程**：需要真正的点播源 API。把你手上的 API 地址发我，我用 `verify_video_source.py` 帮你验证，并接入 `video_source.json`。

## 验证你自己的源

```bash
python3 verify_video_source.py 你的地址列表.txt
# 或
python3 verify_video_source.py 你的video_source.json
# 或
python3 verify_video_source.py https://某个点播源/api/v3/...
```

脚本会检测 HTTP 状态、JSON 结构是否可被 TVBox 解析、返回影片数量，并输出报告。
